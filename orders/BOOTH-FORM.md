# BOOTH の登録画面に入れるもの（これで1回の操作にする）

**上から順に入れれば終わり。** 判断するところはありません。

## 事前に1回だけ

```
cd ~/side-projects/jftc-actions
npm run build:bundle
```

**`build/enforcement-bundle-512-2026-09-07.zip` ができる。これを添付する。**
（`build/enforcement-bundle.zip` も同じ内容。どちらでもよい）

**注文が来るたびに作り直す必要はない。** 買い切りなので、公開時点の内容で固定する。
月次で増えるのは無料版のほうである。

## ショップ設定（初回のみ）

| 項目 | 入れる値 |
|---|---|
| ショップ名 | `eoylab` |
| **オーナー情報**（連絡先・振込先） | **購入者にも外部にも公開されない。**正確に入れる |
| 振込先 | 日本国内の**本人名義**の口座。**振込予定月の19日23:59まで**に登録 |

### 特商法ページ（自動生成される）

`https://<subdomain>.booth.pm/terms` に自動で出る。**「事業者の名称・連絡先」には次を入れる。**

```
省略した事項については、請求により遅滞なく開示いたします。
```

**これは BOOTH の個人ショップの既定の形**（実在の個人ショップ5件で確認済み）。
**成り立つのは、請求されたら実際に開示する場合に限る。**
BOOTH は契約当事者にならず、「各自でご判断ください」としている。

| その他の欄 | 入れる値 |
|---|---|
| 販売価格 | `3000円` |
| 商品代金以外の必要料金 | BOOTH が固定文を入れる（触らない） |
| 代金の支払方法 | BOOTH が入れる |
| 代金の支払時期 | BOOTH が入れる |
| 商品の引渡時期 | `お支払い完了後、すぐにダウンロードできます` |
| 返品等についての特約 | `ダウンロード商品のため、返品・返金・キャンセルはできません。内容が商品説明と異なる場合、またはファイルが開けない場合は、GitHub の Issue（github.com/eoylab/jftc-actions/issues）でご連絡ください。個別に対応します。` |

## 商品の登録

| 項目 | 入れる値 |
|---|---|
| 商品種別 | **ダウンロード商品** |
| 商品名 | 下の「商品名」を貼る |
| 価格 | `3000` |
| 商品画像 | **`creative/product.png`**（1200×1200） |
| ダウンロードファイル | **`build/enforcement-bundle-512-2026-09-07.zip`**（約212KB。上限は1ファイル1.2GB） |
| 在庫 | 不要（ダウンロード商品） |
| 支払方法 | **「注文後すぐに支払済みになるお支払い方法のみを許可する」を オン** |
| タグ | `データセット` `オープンデータ` `景品表示法` `独占禁止法` `下請法` `コンプライアンス` |
| 年齢制限 | なし |

**「注文後すぐに支払済み」をオンにする理由**：オフだと銀行振込・コンビニ払いで最大3日待つ。
ダウンロード商品は入金確認後に渡るので、その間は買った人が待つことになる。

### 商品名

```
景品表示法・独占禁止法・取適法の処分512件を1つの表にしたCSV（出典URL付き・商用利用可）
```

### 商品説明

```
消費者庁と公正取引委員会が公表した処分を、1つの表に揃えたCSVです。

全512件。景品表示法の措置命令・課徴金納付命令が151件、独占禁止法の排除措置命令等と取適法（旧下請法）の勧告が361件。2010年4月から2026年8月まで。全件に出典URLが付いています。

先に3つ書いておきます。買う前に読んでください。

■ 同じ元データは無料で公開しています

消費者庁と公正取引委員会の公表資料で、どちらも公共データ利用規約準拠なので、誰でも無料で商用利用できます。JSON・JSONL・CSVとMCPサーバーをGitHubに置いてあります。

github.com/eoylab/keihyo-cases
github.com/eoylab/jftc-actions

JSONで足りるなら、買わないでください。

■ 売っているのはデータではなく、作業です

3つの法律は所管も記録の形も違います。事件番号が付く記録と付かない記録があり、条項の書き方も年によって変わります。それを15列の共通スキーマに揃える作業が、手作業で2〜3時間かかります。買っていただくのはそこです。

■ 入っていないものがあります

課徴金額は全件入っていません。公表されている一覧表に金額の列がなく、年によってはalt属性が空のPNG画像の中の表にしか存在しないためです。画像から機械で読み取って事実として出すことはしていません。該当する列には、空欄ではなく理由の文字列が入ります。空欄は表計算で並べ替えたときに0として扱われるからです。

代表者氏名も入っていません。処分の公表資料には必ず記載がありますが、収録していません。

「内容」「概要」の記述本文も入っていません。あれは両庁が書いた文章なので、出典URLをお渡しします。

違反かどうかの判定もしていません。各レコードは、既に発出された処分の再記述です。

収録範囲は、公表されている年度別一覧表が返した範囲です。一覧表に載らない措置（確約計画の認定など）は入っていません。網羅していると主張しません。

■ ファイル（ZIP・約211KB）

enforcement-combined.csv — 全512件・15列。UTF-8 BOM付きなのでExcelがそのまま開きます
SOURCES.md — 出典URL181件の一覧
COMMERCIAL-USE.md — 商用利用についての確認書。稟議に添付できる形
README.md — 列の意味と、空欄が何を意味するか

■ 返金について

ダウンロード商品のため、返金・キャンセルはできません。だから入っていないものを上に全部書いています。

内容がこの説明と違う場合、またはファイルが開けない場合は、GitHubのIssueでご連絡ください。個別に対応します。

github.com/eoylab/jftc-actions/issues

■ 更新について

更新は付きません。買い切りはそのときの内容です。月次で更新されるのは無料版のほうで、そちらは自動で増えていきます。

■ 出典

消費者庁ウェブサイト／公正取引委員会ウェブサイト。元データは公共データ利用規約（第1.0版）に準拠します。本データは両庁が作成・公表したものではなく、公表資料から事実項目を抽出・構造化したものです。
```

## 公開したあと

**やることはない。** 受け渡しは購入時点で自動。ダウンロードは**無期限**で、
非公開にしてもショップを消しても、ファイルを削除しない限り購入者は落とせる。

**購入者の個人情報は販売者に渡らない**（ユーザー識別コードのみ）。

売上は **¥201 以上**で振込申請できる（¥5,000 以上は自動）。**6か月で失効する**ので放置しない。

## 収録件数の確認（貼る前に一度）

```
npm run build:bundle
```

出力が **`512 件`** であること。商品説明にも画像にも 512 と書いてあるので、
**ここが食い違ったまま公開すると、説明と中身が違う商品になる。**
