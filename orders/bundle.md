## 先に書いておきます。同じデータは無料です

元データは消費者庁と公正取引委員会の**公共データ利用規約準拠**で、
**誰でも無料で商用利用できます。** JSON / JSONL / CSV と MCP サーバーが両方の repo にあります。

- <https://github.com/eoylab/keihyo-cases>（景品表示法・151件）
- <https://github.com/eoylab/jftc-actions>（独占禁止法・取適法・361件）

**JSON で足りるなら、買わないでください。**

## 買っていただくもの

**2所管の異なる記録を1つの表に揃える作業**と、その周りの書面です。

| ファイル | 中身 |
|---|---|
| `enforcement-combined.csv` | **512件を1つの表に。** 15列の共通スキーマ。**UTF-8 BOM 付きで Excel がそのまま開きます** |
| `SOURCES.md` | 出典URL **181件**の一覧 |
| `COMMERCIAL-USE.md` | **商用利用についての確認書。** 稟議に添付できる形 |
| `README.md` | 列の意味。**空欄が「0」ではなく「その所管が公表していない」であること** |

3つの法律（景品表示法・独占禁止法・取適法）を1つの列構成に揃えるのは、
**手でやると2〜3時間かかります。** ¥3,000 はその置き換えです。

## 空欄の扱い

**空欄は 0 ではありません。** 例：

- `case_number` — 公正取引委員会の勧告には事件番号が付きません
- `penalty_amount` — **全件「（公表一覧に金額の列が無いため未収録）」**。
  年によっては画像内の表にしか無く、**OCR で読んで事実として出していません**

表計算で並べ替えたときに空欄が 0 として下に落ちないよう、
金額列は空欄ではなく理由の文字列を入れてあります。

## 収録していないもの

- **代表者氏名**（処分の公表資料には必ず記載がありますが、持ちません）
- **記述本文**（「内容」「概要」は両庁が書いた文章なので、出典URLを渡します）
- **違反かどうかの判定**（各件は既に発出された処分の再記述です）
