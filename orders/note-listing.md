# note で売る（第2の経路）

> **最初に開けるのは BOOTH。** `orders/booth-listing.md` を見てください。
> **BOOTH のほうが手数料が半分（5.6%＋45円 対 実質約14.5%）**で、**受け取りにも本人確認が要らず**、
> **ダウンロード商品は返金不可が既定**（note は既定で24時間の返金申請が可能）。
>
> **note を残しているのは、読者層が違うことと、note にしかない計測手段があるから。**
> BOOTH は同人・創作の場で、note は文章の場である。
>
> **そして note の `高評価` は購入者しか押せない**（note公式）。**購入者数の下限が外から見える。**
> BOOTH もココナラ以外の全経路も、購入数を公開しない。
> **売れたかどうかを外形的に確認できるのは note だけである。**
>
> **BOOTH で1件出たあと、2つ目の面として使う。**
> 同じ分野の実例：薬機法・景表法のコンプライアンス支援コンテンツが **¥8,000 で購入者7人以上**。


**Stripe より先にこちらを開ける。** 理由は3つ。

| | note | Stripe |
|---|---|---|
| 審査 | **なし。当日から課金できる** | 有効化に通常2〜3営業日＋Japan Security Checklist |
| 販売者の住所・電話番号 | **公開面に出さずに済む**（下記） | 有効化時に事業者情報を登録 |
| 手数料 | 実質 約14.5%＋振込270円 | 3.6% |
| 入金 | 翌月末・¥1,000 以上から | 初回課金から7日後 |

**手数料は note のほうが高い。** それでも先に開けるのは、**いま欲しいのは最初の1件で、
そのために「審査待ち」と「住所の公開」の2つを外せることのほうが効くから**である。
件数が出たら Stripe に移す。

## 販売者情報について（note の一次情報で確認・2026-09-01 更新）

note のヘルプ「特商法の表示について」に、次のとおり書かれている。

> **「販売業者」に該当する場合以外は、掲載する必要はありません。**
> …「業として営む」とは、営利の意思をもって、反復継続して取引を行うことをいいます。

> 原則的には、住所、氏名、電話番号が必要です。ただし、**開示請求があった際に
> 「遅滞なく開示できる場合に限り、その旨を掲載の上、掲載を省略することができる」**とされています。

> 販売者開示請求については、**請求者からクリエイターへではなく、当社宛に**郵送または
> リクエストを送信ページからメールにてご請求いただきます。…
> **断りもなく、当社からクリエイターの個人情報を請求者に開示することはありません。**

**「販売業者」に当たるかどうかは、こちらでは判断しない。** Owner と専門家の領域である。
**どちらであっても安全な形にする**ため、記事末尾に**「請求があれば遅滞なく開示します」の一文を入れる**
——これが note のヘルプが省略を認めている条件そのものだからである。

**Owner の住所・電話番号を記事に書かない。**

## 受け渡しは完全自動にできる

**note は記事にファイルを添付でき、購入した時点で購入者がダウンロードできる。**
上限は **1ファイル 50MB**、こちらのバンドルは **約210KB**。

**つまり注文ごとの作業が発生しない。** `docs/FULFILLMENT.md` の手動手順は、
note を経由しない個別注文のためだけに残す。

**書類の提出も審査もなく、購入者に公開されない**（note のヘルプに明記）。

**以後の継続作業はない。**

## 「返金不可」にする理由と、返金の書き方

**note の既定では、購入者が24時間以内に返金申請できる。**
**ダウンロードできるファイルでこれを開けておくと、ダウンロード後に返金される。**
だから「返金不可」で公開する。

**そのうえで、返金について書けないことを書かない。**
返金不可で公開すると、**note の仕組みを通した返金はできなくなる。**
「説明と違えば全額返金します」と書いても、**実行する手段が無い。**

**書くのはこう。**

> 内容がこの記事の説明と違う場合、またはファイルが開けない場合は、
> GitHub の Issue でご連絡ください。**note の返金機能は使えない設定にしているため、
> 個別に対応します。**

**できることだけ書く。** 実行できない約束は、書いていないより悪い。

## 有料部分の区切りについて

**「ここから下が有料部分です」より上を無料**にする。
**入っていないもの（課徴金額・代表者氏名・記述本文・判定なし）は全部無料部分に置く。**

**買ったあとに気づかれるより、買う前に断られたほうがよい。**
返金しない条件を有料部分の中だけに書くのは、その逆をやることになる。
