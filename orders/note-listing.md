# note で売る（貼るだけの完成版）

**Stripe より先にこちらを開ける。** 理由は3つ。

| | note | Stripe |
|---|---|---|
| 審査 | **なし。当日から課金できる** | 有効化に通常2〜3営業日＋Japan Security Checklist |
| 販売者の住所・電話番号 | **公開面に出さずに済む**（下記） | 有効化時に事業者情報を登録 |
| 手数料 | 実質 約14.5%＋振込270円 | 3.6% |
| 入金 | 翌月末・¥1,000 以上から | 初回課金から7日後 |

**手数料は note のほうが高い。** それでも先に開けるのは、**いま欲しいのは最初の1件で、
そのために「審査待ち」と「住所の公開」の2つを外せることのほうが効くから**である。
件数が出たら Stripe に移す。

## 販売者情報について（note の一次情報で確認・2026-09-01 更新）

note のヘルプ「特商法の表示について」に、次のとおり書かれている。

> **「販売業者」に該当する場合以外は、掲載する必要はありません。**
> …「業として営む」とは、営利の意思をもって、反復継続して取引を行うことをいいます。

> 原則的には、住所、氏名、電話番号が必要です。ただし、**開示請求があった際に
> 「遅滞なく開示できる場合に限り、その旨を掲載の上、掲載を省略することができる」**とされています。

> 販売者開示請求については、**請求者からクリエイターへではなく、当社宛に**郵送または
> リクエストを送信ページからメールにてご請求いただきます。…
> **断りもなく、当社からクリエイターの個人情報を請求者に開示することはありません。**

**「販売業者」に当たるかどうかは、こちらでは判断しない。** Owner と専門家の領域である。
**どちらであっても安全な形にする**ため、記事末尾に**「請求があれば遅滞なく開示します」の一文を入れる**
——これが note のヘルプが省略を認めている条件そのものだからである。

**Owner の住所・電話番号を記事に書かない。**

## 有料部分の区切りについて

**「ここから下が有料部分です」より上を無料**にする。
**入っていないもの（課徴金額・代表者氏名・記述本文・判定なし）は全部無料部分に置く。**

**買ったあとに気づかれるより、買う前に断られたほうがよい。**
返金しない条件を有料部分の中だけに書くのは、その逆をやることになる。
