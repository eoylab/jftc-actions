# Hosted API — 月 ¥9,800

**まだ存在しません。** このページは需要の計測に使っています。

自分でホストせずに叩けるエンドポイント。

```
GET /actions?company=&provision=&stream=&since=&until=
GET /actions/{id}
```

- 認証はトークン1本
- 個人・検証用は無料枠
- SLA なし・レート上限あり（保証が必要な場合は[商用ライセンス](license.md)）

## なぜ月 ¥9,800 なのか

同じ領域で公表価格のある最も近い商品が、**公取委の審決全文を日次更新で提供する法情報DBの
月 ¥9,000（税別）**です。ほぼ同水準に置いています。

ただし**あちらは審決の全文、こちらは現行の措置の構造化**で、同じものではありません。
2013年の審判制度廃止以降、審決はほとんど発生していません。
