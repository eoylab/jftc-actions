# 導入支援 — 一括 ¥120,000

**まだ存在しません。** このページは需要の計測に使っています。

「データはあるが、自社の台帳・BI・審査フローに繋ぐ工数がない」場合です。

- MCP / API の組み込み
- 自社の取引先マスタとの法人番号による名寄せ突合
- 抽出項目の追加

## なぜ一括 ¥120,000 なのか、そして上限を置く理由

3人日 × ¥40,000。10営業日で納めます。

**契約に「月2件まで」と書きます。** これは値付けではなく設計です。
導入支援は**契約数に比例して人手が増える唯一の商品**なので、
上限を書かないと、売れたときに事業が止まります。
