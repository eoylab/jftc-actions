# 商用ライセンス / 稼働保証 — 年 ¥120,000

**まだ存在しません。** このページは需要の計測に使っています。

元データは公正取引委員会で**公共データ利用規約（PDL1.0）準拠**、コードは MIT です。
**現状のデータセットと MCP サーバーは、そのまま商用利用できます。** 許可を買う必要はありません。

これが要るのは、**社内稟議に提供元の保証が必要な場合**です。

- 月次更新の保証
- スキーマの後方互換の保証
- 誤りの訂正手順と連絡先
- 収録範囲の明示（何を収録していないかを含む）

## なぜ年 ¥120,000 なのか、そして正当化できない部分

比較対象の法令アラートサービスが月 ¥21,010（税込）＝**年 ¥252,120**。その半額以下です。

**ただし正直に書くと、手作業の置き換えコスト（年 ¥95,200）を上回っています。**
人件費の置き換えでは正当化できません。正当化できるのは次の2点だけです。

1. **見落としゼロの保証**（人が巡回する限り、抜けは必ず起きる）
2. **課徴金額の構造化**（後述。現在どこにも構造化されていない）

**この2点に払う人がいなければ、この価格は年 ¥59,760 まで落ちます。**
それを測るためにこの価格を先に出しています。

## 課徴金額について

**現在のデータセットは課徴金額を持っていません。** 全件 `penalty_amount: null` です。
公表されている年度別一覧表に金額の列が無く、年によっては
**alt が空の PNG 画像の中の表**にしか存在しないためです。

**OCR で読んで事実として出すことはしません。** 機械が画像から読んだ金額が
誰かの稟議書に引用される事故を作りたくないので、`penalty_status` で理由を明示して null にしています。

**この構造化に払う人がいるなら、それが最初に作るものです。**
