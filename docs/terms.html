販売条件・よくある質問

同じ元データは無料です。 消費者庁と公正取引委員会の公表資料で、公共データ利用規約準拠なので誰でも無料で商用利用できます。 JSON / JSONL / CSV と MCP サーバーが keihyo-cases と jftc-actions にあります。 JSON で足りるなら、買わないでください。

何を売っているのか

データではなく、作業です。3つの法律（景品表示法・独占禁止法・取適法）の、 所管も記録の形も違う処分を1つの表に揃える作業。手作業では2〜3時間かかります。

価格¥3,000（税込）買い切り。月額ではありません
形式ZIP（約210KB）。ファイル4点
収録件数512件（景品表示法 151／独占禁止法・取適法 361）。2010-04 〜 2026-08
enforcement-combined.csv全512件・15列の共通スキーマ。UTF-8 BOM 付きで Excel がそのまま開きます
SOURCES.md出典URL 181件の一覧
COMMERCIAL-USE.md商用利用についての確認書。稟議に添付できる形
README.md列の意味。空欄が何を意味するか

収録していないもの

買う前に読んでください。買ったあとに気づかれるより先に書いておきます。

  • 課徴金額。全件入っていません。公表されている一覧表に金額の列がなく、 年によってはalt が空の PNG 画像の中の表にしか存在しないためです。 OCR で読んで事実として出すことはしていません。該当列には空欄ではなく理由の文字列が入ります （空欄は表計算で 0 として並べ替えられるため）
  • 代表者氏名。処分の公表資料には必ず記載がありますが、収録していません
  • 記述本文。「内容」「概要」の文章は両庁が書いたものなので、出典URLを渡します
  • 違反かどうかの判定。各レコードは既に発出された処分の再記述です

収録範囲は、公表されている一覧表が返した範囲です。 一覧表に載らない措置（確約計画の認定など）は入っていません。 網羅していると主張しません。何が入っていないかは同梱の README.md と、 無料版の data/meta.json / data/unparsed.json で確認できます。

どう届くか

購入BOOTH の商品ページ。BOOTH が対応する決済方法が使えます
受け渡しお支払いの完了と同時にダウンロードできます。連絡待ちはありません
再ダウンロード期限はありません。BOOTH の購入履歴から何度でも落とせます
中身公開時点の内容で固定した買い切りです。注文ごとに作り直しません。 月次で増えるのは無料版のほうです
返品ダウンロード商品のため、返品・返金・キャンセルはできません。 内容が商品説明と異なる場合、またはファイルが開けない場合は Issue でご連絡ください。個別に対応します

購入者の氏名や住所は販売者に渡りません。BOOTH から受け取るのは注文の識別情報だけです。

返金・キャンセル

受け渡しは支払いの完了と同時なので、途中でキャンセルできる時間帯がありません。 ダウンロード商品として、返品・返金・キャンセルはできない設定で公開しています。 デジタルデータで返却ができないためです。

だから収録していないものを、買う前に上に書いています。 判断がつかない場合は、買わずに無料版を先に見てください。 JSON で足りるなら買わないでください。

内容がこのページの説明と違う場合、またはファイルが開けない場合は、 Issue でご連絡ください。個別に対応します。 ——ここで「全額返金します」と書かないのは、ダウンロード商品を返金不可で公開しており、 その返金手段を実際には持っていないためです。 実行できない約束は、書いていないより悪いと考えています。

よくある質問

無料の JSON と何が違うのですか

データは同じです。違うのは、2所管の異なる記録が1つの表に揃っていること、 出典URLが1ファイルにまとまっていること、商用利用の確認書が付いていることの3点です。 自分で揃える時間があるなら、無料版で足ります。

更新は付きますか

付きません。買い切りは、そのときの内容です。 月次で更新されるのは無料版のほうで、そちらは自動で増えていきます。 更新の通知や保証が必要な場合は 別のtierを見てください（こちらもまだ作っていません）。

再配布してよいですか

元データは自由に使えます（公共データ利用規約準拠・商用可）。 同梱の COMMERCIAL-USE.md に出典表記と加工の明示の条件が書いてあります。 権利を売っているのではありません——権利はもともと誰にでもあります。

法人で買えますか。請求書は出せますか

BOOTH の購入手続きの中で領収書を発行できます。それ以外の書式が必要な場合は Issue でお知らせください。必要な書式を教えていただければ合わせます。

データが間違っていたら

Issue で教えてください。 全レコードに出典URLが付いているので、突き合わせられます。 修正した場合は無料版にも反映し、購入者にお知らせします。

販売者について

事業者の表示は BOOTH のショップ側に出ています （特定商取引法に基づく表記）。 連絡は Issue か、 BOOTH のショップへのお問い合わせから受け付けます。

このページを「特定商取引法上必須の表示」とは書きません。 どの表示がどこまで必要かの当てはめは専門家の領域で、 ここに書いているのは当方の販売条件そのものです。
